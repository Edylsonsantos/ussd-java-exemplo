# Projeto USSD (Simulação M-pesa)
Este projeto é uma simulação em Java do funcionamento básico de um sistema de USSD como o utilizado no M-Pesa, permitindo interações simples como transações, consultas e operações com carteira móvel.

---

## 📌 Funcionalidades

- Simulação de interface USSD via terminal
- Menu de navegação tipo M-Pesa (Enviar Dinheiro, Levantar, etc.)
- Validação básica de entradas
- Operações simuladas de carteira digital

---

## 🛠️ Tecnologias Utilizadas

- Java (JDK 8+)
- NetBeans (estrutura de projeto compatível)
- Simulação em modo console/terminal

---

## ▶️ Como Executar

1. **Abra o projeto no NetBeans** ou outro ambiente compatível com Java.
2. Compile o projeto.
3. Execute a classe principal `carteiraMpesa.java`.
4. Use o terminal para interagir com o menu USSD simulado.
